## How to Compare

```bash
# Build with Xcode
cd Xcode
xcodebuild -workspace OpenCoder.xcworkspace \
  -scheme OpenCoder \
  -configuration Release \
  -sdk iphoneos \
  -derivedDataPath /tmp/XcodeBuild \
  clean build \
  CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO

# Convert Xcode plist to XML
plutil -convert xml1 \
  /tmp/XcodeBuild/Build/Products/Release-iphoneos/OpenCoder.app/Info.plist \
  -o /tmp/xcode_info.plist

# Build with Bazel
cd ..
bazel build //:Info_plist -c opt

# Compare
diff /tmp/xcode_info.plist bazel-bin/Info.plist
```
